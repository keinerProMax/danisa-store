# routes/

**Responsabilidad:** definición de rutas de la aplicación.

**Archivos:** ninguno actualmente. El "ruteo" de esta SPA se maneja completamente dentro de `controllers/router.js` mediante manipulación de clases CSS sobre elementos `.page`, sin un sistema de rutas declarativo separado.

**Cuándo usarla:** al introducir un sistema de rutas declarativo (mapa de rutas, rutas de backend, etc.) separado de la lógica del controlador.
