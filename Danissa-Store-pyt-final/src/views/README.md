# views/

**Responsabilidad:** interfaces, fragmentos HTML y estilos visuales de la SPA.

**Archivos:**
- `pages/` — Fragmentos HTML inyectados dinámicamente en los slots de `index.html` (navbar, home, shop, cart, profile, contact, footer, auth-modal).
- `css/` — Hojas de estilo: `variables.css`, `nervar.css`, `pages.css`, `centrado.css`.

**Cuándo usarla:** al modificar el markup de una página, agregar un nuevo fragmento HTML, o tocar estilos visuales.
